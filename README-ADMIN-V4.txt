BẢN ADMIN V4

Đã thêm:
- Nút GỌI và NHẮN ZALO ngay trên từng ứng viên.
- Lọc theo công ty + trạng thái.
- Trạng thái có màu rõ ràng.
- Ghi chú HR có nút LƯU và báo ĐÃ LƯU.
- Hiển thị ngày có thể đi làm + ghi chú của ứng viên.
- Giao diện admin riêng cho điện thoại dạng card, không phải bảng ngang khó xem.
- Giữ xuất Excel/CSV.

QUAN TRỌNG:
File .env.local trong gói này để trống nhằm không phát tán thông tin kết nối.
Hãy COPY file .env.local đang chạy tốt ở thư mục cũ của bạn sang thư mục bản mới này, rồi chạy:
  npm install
  npm run dev

Trang admin:
  http://localhost:3000/admin
